# 💰 WHO WANTS TO BE A BILLIONAIRE? — Edisi Pembelajaran

Kuis tangga hadiah 15 tingkat bergaya acara TV untuk **IFP / layar sentuh / proyektor kelas**.
Satu file `index.html` — tanpa install, tema mewah emas-gelap, lengkap **mode kamera AR** (tunjuk jawaban dengan telunjuk, dideteksi AI).

---

## 🚀 Cara Menjalankan

1. Salin `index.html` ke laptop/IFP (cukup 1 file, bisa via flashdisk).
2. Buka dengan **Google Chrome / Microsoft Edge**.
3. Klik **⛶ layar penuh** → **🎮 MULAI BERMAIN**.
4. Mode kamera: klik **"Izinkan"** saat browser meminta akses kamera.

> 💡 Internet hanya perlu saat **pertama kali** memuat modul AI. Mode sentuh 100% offline.

## 🎮 Aturan Main (sesuai acara TV)

| Elemen | Ketentuan |
|---|---|
| Tangga hadiah | 15 soal beruntun: Rp 1.000 → … → **Rp 1 MILIAR** 🏆 |
| Batas aman | **Lv 5 = Rp 10.000** dan **Lv 10 = Rp 100.000**. Salah jawab = tetap bawa hadiah batas aman terakhir yang sudah dilewati |
| Waktu | 15/30/45/60 detik per soal (bisa diatur). Habis waktu = gugur |
| Drama kunci | Setiap memilih, jawaban "dikunci" dengan detak jantung ±1,6 detik sebelum diumumkan 🔥 |
| Berhenti | Tombol **🎁 Berhenti & Bawa Hadiah** — bawa pulang hadiah yang sudah diraih |
| Kesulitan | Lv 1–5 mudah • Lv 6–10 sedang • Lv 11–15 sulit (otomatis) |

## 🆘 4 Bantuan (sekali pakai)

1. **✂️ 50:50** — dua jawaban salah dihapus
2. **👥 Tanya Audiens** — kelas memberi voting (grafik batang; kelas lebih yakin di soal mudah)
3. **📞 Telepon Teman** — "teman" memberi saran (akurasi menurun di soal sulit)
4. **🔄 Ganti Soal** — tukar dengan soal lain setingkat

## 🤖 Dua Cara Menjawab

- **Kamera AI (AR)**: layar jadi cermin kelas; **tunjuk pilihan dengan telunjuk**, tahan ±1 detik sampai bar emas penuh.
- **Sentuh/Mouse**: ketuk langsung pilihannya.

## 🏆 Papan Juara

5 skor terbaik tersimpan otomatis di browser (nama, hadiah, level) — tampil di akhir game & dari menu.

## ✏️ Soal Guru

Menu **✏️ Soal Guru** → satu soal per baris:
```
Pertanyaan | Jawaban Benar | Salah 1 | Salah 2 | Salah 3
Singkatan dari HTML? | HyperText Markup Language | High Text Machine Language | Hyper Tool Multi Language | Home Tool Markup Language
```
Bersama **Gesture Battle**, soal ini **berbagi bank soal** (disimpan di browser yang sama) — cukup input sekali!

## 📚 Kategori

🎲 Campuran • 🧮 Matematika (otomatis per tingkat) • 🌍 Pengetahuan Umum (42+ soal, termasuk lokal Jateng/Banyumas) • ✏️ Soal Guru

## ❓ Penyelesaian Masalah

| Masalah | Solusi |
|---|---|
| Kamera tidak aktif | Cek izin kamera di Chrome; gunakan Chrome/Edge terbaru |
| "Memuat AI…" lama | Perlu internet saat pertama kali; setelahnya ter-cache |
| Tangan tak terdeteksi | Dekati kamera, tunjuk 1 telunjuk, cahaya cukup |
| Fullscreen gagal | Buka file langsung di Chrome (bukan dalam preview/aplikasi lain) |
